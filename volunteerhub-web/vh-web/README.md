# VolunteerHub (web demo)

A demo website for nonprofit volunteer management (FBLA Coding & Programming 2026–27 topic).

## Run it
Open `index.html` in a browser, or in VS Code right-click it → **Open with Live Server**.

Demo accounts (password `demo1234`):
- Volunteer: volunteer@demo.org
- Coordinator: coordinator@demo.org

Data is sample data for a fictional organization and is saved in your browser only. Use "Reset demo data" at the bottom of the app to start over.
